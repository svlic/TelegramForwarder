## Changes

### 1. `/delete_rule` cascade IntegrityError
- **Root cause**: `Keyword.rule_id` is NOT NULL; deleting `ForwardRule` without removing children failed.
- **Fix**:
  - `models/models.py`: `ForwardRule.keywords` uses `cascade="all, delete-orphan"` (aligned with other child relationships).
  - `handlers/command_handlers.py` `handle_delete_rule_command`: explicitly deletes `ReplaceRule`, `Keyword`, `MediaExtensions`, `MediaTypes`, and both `RuleSync` directions before `session.delete(rule)`; per-rule `commit`/`rollback`.

### 3. `regex_safety` timeout not killable
- **Root cause**: thread-pool based timeout cannot terminate a stuck `re` engine.
- **Fix**: `utils/regex_safety.py` rewritten to run regex in a **child process** (`multiprocessing`); on timeout `terminate`/`kill` the worker and raise `RegexTimeoutError`.

### 5. Summary task held DB session across network I/O
- **Root cause**: `_execute_summary` kept `get_db_session()` open during Telegram/AI awaits.
- **Fix**: `scheduler/summary_scheduler.py` snapshots rule scalars inside a short `with get_db_session()` block, then closes session before network/AI work.
